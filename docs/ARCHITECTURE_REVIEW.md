# 0.4.0 源码与产品链路梳理

这次重新检查了 Uniterm 的 AppHeader、TabsList、TabItem、BaseTerminal、Menu/子菜单、终端主题、输入/粘贴处理，以及 Go 的本地会话、读写、调整尺寸和断开设计。FnTerminal 保留开源终端组件与视觉体系，重新建立 fnOS 的连接、权限、生命周期和可观测性契约。不会把桌面 Wails 绑定或未移植协议伪装成可用功能。

## 连接协议

1. 可信UDS对端 + 唯一数字UID + 严格管理员标志，是所有HTTP/API/WS的首要边界。
2. GET `/api/bootstrap` 返回协议版本和短期CSRF准备凭据，不提供CORS授权。
3. POST `/api/connect` 必须携带JSON、自定义CSRF头和有效Origin；消费凭据，检查模式/资源/上限，返回15秒一次性票据。
4. `/ws?ticket=...` 校验同一UID/Origin并消费票据，预留并发配额，再启动PTY和独立监督器。
5. 监督器私有FD确认实际Shell/SSH程序执行成功后才发送ready。失败发送结构化错误，保留在该用户的诊断日志里。
6. 二进制PTY输出由xterm解析，解析完成ACK；有界窗口产生背压。输入/帧/创建均有限速，退出回收不依赖http.Server处理劫持的WS。
7. 每20秒通过网关HTTP续期，服务端60秒租约绑定原UID和Origin；注销后不能续期。无输入15分钟/寿命8小时独立于输出与ping。
8. 监督器回报退出码；SSH认证拒绝不再被标成普通断连。日志不包含按键、终端输出、密码、令牌或私钥。

## 权限与部署

生产服务始终UDS、run-as=package，无额外终端TCP、Docker、系统资源或默认root。NAS权限只在明确打开SSH终端并由sshd二次认证后产生。SSH远端用户主动创建的脱离任务不属于应用本地进程树，不宣称能跨账户强杀它们。

Linux测试机是Apple Virtualization启动的Alpine ARM64内存系统，无NAS连接、无主机目录挂载。root仅用于模拟可信网关/sshd及系统生命周期调用；生产Go与PTY使用UID/GID700，SSH认证后使用独立UID701。虚拟机退出即销毁测试账户与自动生成的密钥。

真实fnOS管理员Header覆盖规则、网关UID/ACL、具体Intel系统兼容性和应用中心安装/升级/卸载仍需要用户机器回归。源码和包结构验证不替代真实FPK安装验收。

## 0.5.0 默认 SSH 与连接配置

独立应用账户承担常驻服务和PTY监督器的最小权限身份；日常入口改成SSH，首次弹窗填写并保存，不自动创建应用Shell。上次选择的配置只保存ID，重新打开读取经过验证的配置，单次尝试SSH；失败留在错误页面供编辑/重连，不静默回退到应用Shell。＋及Ctrl+Shift+T新建SSH配置，应用Shell只在高级诊断明确创建。

每个标签复制连接配置；保存配置不影响现有标签，保存并重连只递增当前标签的连接版本并关闭旧传输。配置白名单不含凭据。NAS密码仍通过OpenSSH交互，首次确认指纹，保存known_hosts，拒绝密钥变化。HTTP JSON及helper均校验主机/端口/用户名，使用独立argv传递，数字用户名不被误拒；预检和SSH使用同一个目标。

Linux生产测试完成22、10022与数字用户名10001三条真实SSH链路；Chrome检查首次无应用Shell、弹窗保存/编辑、恢复最近配置。图标转换RGBA，FPK验证同时检查透明通道。增加Element Plus基础主题变量以恢复遮罩、关闭图标及弹窗边界，保持Uniterm组件和配色。

## 0.6.0 稳定性与连接管理界面

浏览器偏好只接受对象并逐字段验证，模块初始化不再写存储；读写异常回退当前页面默认值，连接保存失败仍允许临时连接，不记为已保存或最近连接。配置列表事务化更新，减少写入失败的虚假卡片；删除失败保留原列表。新增自动连接开关，关闭后启动不创建PTY。

连接列表替换为Uniterm主题卡片，提供名称/主机/端口/用户名搜索、选中提示、新建配置、未保存修改标记与包含目标的保存成功卡。桌面两栏、手机纵向，减少多次进入菜单；断连直接编辑。移除不再使用的ElSelect/ElOption组件与样式，JS约763KB→677KB。

会话结束原因使用原子指针保存第一条实际原因，消除超时日志一律disconnect的问题；关闭帧的空闲/寿命/租约/服务停止原因分类显示；协议/流量拒绝明确发送1008关闭帧，1009数据过大单独显示。网络导致续期不可确认时仍失败关闭，文案不冒充明确注销。SSH标签展示通道已建立而非账户认证结果；异常退出不一律归因于密码错误。

移动触摸输入延迟至松手，超过8px视为滑动；指针捕获保证手指移出按钮后不误输入，横向移动只改变scrollLeft，取消触摸不输入；按钮40px并支持安全区。Chrome使用实际触摸输入验证。真实手机IME/键盘/剪贴板仍待验证。新增OpenSSH保活15秒/3次，不续期应用空闲时间，也不添加凭据存储或提权。

## 0.7.0连接数据与发布保障

导入文件先检查完整schemaVersion1/app标识、大小、条数和字段白名单，再验证各行地址/端口/用户名，全部合法才合并。键由规范化主机、端口、用户名组成，IPv6等价形式和域名大小写可去重；旧ID与名称保持，新连接生成ID。写入成功才更新UI，没有替换模式或隐式启动会话。导出不包括密码、令牌、私钥、ID或登录态。

草稿与初始表单快照比较，切换/新建/删除/关闭提供内联保留或放弃选择。撤销只恢复最近删除的元数据，在当前弹窗内有效。当前活动终端仍持有自己的配置快照。

诊断拆为独立组件，摘要和事件列表使用Vue文本输出，原始JSON折叠与下载；HTTP错误显式展示，10秒超时，代际控制与AbortController避免关闭/刷新后的旧响应覆盖。生产鉴权、监听方式和Shell权限没有扩展。发布脚本验证每项检查、同版本浏览器证据、最终FPK哈希与源码归档，fnOS验收保持独立。

## 0.9.0布局边界

布局几何统一放入layout.css，最后加载，颜色仍由Semi主题控制。弹窗按可见视口居中，固定header/footer且body独立滚动；低高度减少外边距，短窗口不裁切操作区。正文控件使用min-width:0与明确换行/省略策略，不靠页面overflow:hidden掩盖过宽内容。
